# Respuesta Única Parcial
__Pregunta 1:__ ¿Qué es un método de clase en programación orientada a objetos?

Respuesta: b) Un método que puede ser llamado directamente desde la clase sin crear una instancia.

__Pregunta 2:__ ¿Cuál es la función principal del módulo unittest en Python?

Respuesta: a) Permitir realizar pruebas unitarias para verificar el comportamiento del código.

__Pregunta 3:__ ¿Cuál es la función de un constructor en una clase?

Respuesta: c) Inicializar los atributos del objeto cuando se crea una instancia de la clase.

__Pregunta 4:__ ¿Qué palabra clave se utiliza en Python para finalizar anticipadamente un bucle for o while?

Respuesta: b) break

__Pregunta 5:__ ¿Qué sucede si una función en Python no tiene una declaración return?

Respuesta: a) La función devuelve None automáticamente.

__Pregunta 6:__ ¿Cómo se accede a un método estático en una clase de Python?

Respuesta: b) Llamándolo directamente desde la clase, sin necesidad de crear una instancia.

__Pregunta 7:__ ¿Qué hace la función integrada map en Python?

Respuesta: b) Aplica una función a cada elemento de un iterable y devuelve un objeto iterable.

__Pregunta 8:__ ¿Qué hace el método pop en una lista de Python?

Respuesta: b) Devuelve y elimina el último elemento de la lista o un elemento en un índice específico.

__Pregunta 9:__ ¿Qué sucede si se intenta dividir un número por cero en Python?

Respuesta: b) Python lanza una excepción ZeroDivisionError.

__Pregunta 10:__ ¿Cuál es el propósito del método __str\_\_ en una clase de Python?

Respuesta: b) Formatear el objeto como una cadena para su impresión.

__Pregunta 11:__ ¿Qué es un widget en Tkinter?

Respuesta: b) Un componente gráfico que permite interactuar con la interfaz.
